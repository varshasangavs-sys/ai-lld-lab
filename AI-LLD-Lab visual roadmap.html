The project

Small service businesses like clinics, salons and coaching centres get hundreds of repetitive customer messages a day: “When are you open?”, “What does the premium plan include?”, “Move my appointment to Friday.” Staff lose hours answering the same questions and rescheduling by hand. You’ll build the backend of an AI support platform that handles this end to end.

What you’ll have on Day 35

  • A live platform on Vercel with a chat UI that answers questions, checks availability and books appointments.
  • A public GitHub repo with CI, tests, Docker setup and a clean layered structure.
  • A design doc per module, a capstone design doc and a 35-entry pattern journal.
  • All 23 Gang of Four patterns, UML, data design, concurrency and deployment used in your own code.
  • A project you can demo and defend line by line in LLD interviews, and reuse as a freelance template.

Before Day 1

  • Skills: Python classes and type hints, FastAPI basics, basic SQL, Git.
  • Tools: Python 3.12+, uv, Docker Desktop, VS Code. Node.js is needed from Day 34.
  • Accounts: GitHub now; Vercel and free-tier hosted Postgres and Redis by Day 31.
  • Optional: an LLM API key. The fake client covers every day until you want real answers.
